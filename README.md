# 🎂 Interactive Tamil Birthday Website

A **highly animated, interactive and cinematic Birthday Website** designed to create a memorable digital birthday experience.
The website combines **Tamil birthday wishes, photo memories, animated effects, surprise interactions, fireworks, confetti and smooth motion effects**.

## ⚙️ Customization

You can easily change the birthday person's details.

### Change Name

Find:

```html
[BIRTHDAY PERSON NAME]
```

Replace it with the person's name.

Example:

```html
AREESH
```

### Change Tamil Wishes

Search the HTML file for the existing Tamil quotes and replace them with your own wishes.

### Add Photos

Place your images inside:

```text
assets/images/
```

Then update the image paths:

```html
<img src="assets/images/photo1.jpg" alt="Birthday Memory">
```

### Add Birthday Music

Place your audio file inside:

```text
assets/music/
```

Then connect it to the music player.

## ▶️ How to Run

### Method 1 — VS Code

1. Download or clone this repository.
2. Open the project in **VS Code**.
3. Open `index.html`.
4. Use **Live Server**.
5. Open the generated local URL in your browser.

### Method 2 — GitHub Pages

1. Upload the project to GitHub.
2. Open **Repository Settings**.
3. Select **Pages**.
4. Select the main branch.
5. Save.
6. GitHub will generate your website URL.
